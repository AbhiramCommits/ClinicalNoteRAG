# ClinicalNoteRAG

Citation-grounded retrieval-augmented generation over **synthetic** FHIR R4
bundles and synthetic clinical/payment notes for treatment, payment, and
operations (TPO) question answering.

> Research prototype only. Not for clinical use. All data is generated by code
> in this repository; no real patient data or PHI is included or downloaded.

The full research report, measured results, architecture and run instructions
are completed in the final documentation step. For now:

```bash
make setup
make gen
make ingest
make serve
```

See `docs/` for the research report, model card and AI governance notes.
